## 📌 Project Overview
This project implements a **Fake News Detection System** using Natural Language Processing (NLP) and Deep Learning.  
A Bidirectional LSTM model is used to classify news articles as **Real** or **Fake**.

---

## 🧠 Tech Stack
- Python  
- TensorFlow / Keras  
- NLP Tokenization  
- LSTM Neural Network  
- Pandas & Scikit-learn  

---

## 🚀 Features
- Text preprocessing and cleaning  
- Tokenization and word embedding  
- Bi-directional LSTM model  
- Accuracy evaluation and confusion matrix  

---

## 🏗️ System Workflow
1. Data collection (Fake & Real news datasets)  
2. Text preprocessing  
3. Tokenization and padding  
4. LSTM model training  
5. Model evaluation and prediction  

---

## 📊 Applications
- Social media misinformation detection  
- News verification platforms  
- Cyber security and media monitoring
